# Limit version 2 to pre-submission Catalog Form Behavior

Version 2 will generate tests only for Catalog Form Behavior within the Pre-Submission Boundary, supporting form-load and variable-change expectations without ordering or submitting the Catalog Item. `ON SUBMIT`, Request and Requested Item creation, Catalog Tasks, approvals, assignment, fulfillment flows, downstream statuses, transactional cleanup, and their related fields remain future Fulfillment Design; this keeps the variable, UI Policy, Client Script, and Script Include contract compiler coherent while deferring the materially different lifecycle and operational costs of generated fulfillment tests.
