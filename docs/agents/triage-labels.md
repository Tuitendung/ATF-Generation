# Triage Labels

The engineering skills use five canonical triage roles. This file maps those roles to the label strings used by the Local Markdown issue tracker.

| Canonical role | Label in this tracker | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer needs to evaluate the issue |
| `needs-info` | `needs-info` | Waiting for the reporter to provide information |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for an autonomous agent |
| `ready-for-human` | `ready-for-human` | Requires human implementation |
| `wontfix` | `wontfix` | Will not be actioned |

When a skill refers to a canonical triage role, use the corresponding value from the second column as the issue's `Status:` value.
